\begin{abstract}
工具调用智能体即使正确完成任务，也可能在可选参数中披露当前操作并不需要的敏感信息。本文将这种现象定义为冗余参数泄露（Redundant Parameter Leakage, RPL），并提出 RPLBench Builder：一种把公开多工具基准转换为 RPL 评测数据的可复现方法。每个任务保留上游标准调用作为不泄露参照，并构造仅在可选参数中增加同名同值敏感字段的泄露参照；授权关系由稀疏白名单定义，其补集即为禁止披露。基于锁定版本的 $\tau$-bench、BFCL、API-Bank 与 AppWorld，本文构建 328 条完整 reference 轨迹，全部通过独立校验与源重放。正式转换与发布门禁不调用智能体或外部模型，身份冲突与字段语义歧义由确定性保守规则过滤。本文提供可复现的数据构造与环境执行证据，而不将参照调用冒充全局最小路径或人工金标准。

\noindent\textbf{关键词：}工具调用智能体；隐私披露；数据最小化；冗余参数泄露；数据集构建；可复现评测
\end{abstract}
